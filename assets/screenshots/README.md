# Screenshot checklist

Add only sanitized screenshots to this folder. Recommended names are listed in the root README.

Before adding an image, verify that it does **not** reveal:

- Client, employee, supplier, or user names
- Addresses, phone numbers, email addresses, DPI/ID numbers, bank information, or signatures
- Real project budgets, costs, invoices, financial totals, or contractual details
- Private evidence photographs or uploaded documents
- Browser URLs containing private domains, IP addresses, development ports, tokens, or query values
- Notification contents, personal browser tabs, or developer tools

Use fictional or anonymized data, crop to the product surface when possible, and prefer WebP or PNG at approximately 1440 × 900 pixels.
